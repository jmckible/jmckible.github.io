Wcloses a tab, or parks an app, and knows which

Stock, SUPER+W closes the window, the same as SUPER+Q. Then keyd made it CTRL+W, whatever the window was.

A Chromium app window is a single tab, so CTRL+W took the whole renderer down with whatever the page still had in flight. A slow Gmail lost archives on the way out. keyd rewrote the key below the compositor and could never be window-aware.

So tab-closing moved up into Hyprland: park when the focused window carries the docked tag, inject CTRL+W otherwise, the same way Omarchy's universal clipboard binds inject theirs. SUPER+Q still closes.

what it is
One bind in bindings.lua, reading hl.get_active_window().tags.
the tag
Emitted by the same generator that lays out the scratchpads, so the bind and the roster can't disagree about what is docked.
keyd
Stops remapping the key. Its templates keep one remap block each. What's left is SUPER+R to CTRL+R, which doesn't care which window has focus.

Sfixed and dismissible Slack and Gmail

Stock has one scratchpad on SUPER+S. Past that, Slack and Gmail hold tiles all day, or hide on a workspace you forget.

Communication apps are glanced at, not worked in. Each gets a pinned box on the first workspace, always in the same place, and a key that either focuses it or summons it. Park it and it is gone; press the key and it is back where it was.

The geometry is generated from the live monitor, the bar height and the gap settings, never hand-written. A path unit regenerates it whenever any of those change, so a scale change from Omarchy's own Display panel cannot leave the grid stale.

what it is
pyprland scratchpads, a generator that writes both its config and the Hyprland window rules, and a bar widget.
the keys
Slack SUPER+S, Discord SUPER+D, McKible Mail SUPER+CTRL+M, Vocal Mail SUPER+ALT+M.
unread
Slack's bar icon lights from its tray item, so hidden and signed-out look different. Slack publishes a StatusNotifierItem whose tooltip is a closed set of three strings. Matching them literally is the whole parser.
layouts
A 3-column grid on the desktop, a 2×2 on the laptop. Same keys on both.

Most of the day happens in a browser, which makes the web the most important part of my omakase. Its defining tool is uBlock Origin, and it is ghastly that Chrome abandoned it. Helium ships with it and still runs it, so Helium is the browser here, for every link and every web app.

On X, the screenshot is the whole page: one column of posts. The nav rail, the trends, who-to-follow and the upsells are gone. The last mile was making what's left look like it belongs on this desktop. Umber stamps the Omarchy palette onto every page as custom properties and applies one plain CSS file per site; change the desktop theme and the tabs retint in place.

That last mile is where agents excel: understanding any page and adapting it. X is three design systems in one document, and the one most of it runs on writes its colours into inline style attributes. Nobody should hand-write 700 lines of CSS against that. An agent reads it, maps what it finds onto the palette, and every save restyles the open tab while I watch.

browser
Helium, with uBlock Origin bundled and Widevine not. install/helium.sh adds Mozilla's copy of the CDM and makes Helium the default for both $BROWSER and xdg.
theme
Umber: an unpacked Chromium extension plus a native messaging host that watches omarchy-theme-color. Starters for Omarchy Radio, Gmail, GitHub and X.
agent
"Theme with agent" in Umber's popup hands omarchy-default-agent a census of the rendered page and a screenshot, in a floating terminal pointed at the site's file.
